# Aero Sings Scarborough Fair

A 108-second procedural singing film: a physical-modeling voice, fingerpicked guitar and bowed cello
synthesized from scratch in pure Python, with hand-drawn ink & watercolor frames painted live on Canvas 2D.

Open `scarborough_fair_aero.html` and click the cover sheet to start playback. Everything — audio, artwork,
timeline — is embedded in that single file; there are no external requests.

Upstream project and full source: [ChetasLua/aero-scarborough-fair](https://github.com/ChetasLua/aero-scarborough-fair).
